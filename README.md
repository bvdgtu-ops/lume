# Lume — живые обои для Windows 10/11

Бесплатное open-source приложение для анимированных обоев на рабочем столе (аналог Wallpaper Engine):
видео, веб-страницы и интерактивные обои за иконками рабочего стола, с библиотекой,
настройкой каждого обоев, поддержкой нескольких мониторов и авто-паузой в играх.

![Лицензии зависимостей](https://img.shields.io/badge/deps-MIT%20%7C%20Apache%20%7C%20LGPL-green)

## Возможности

| Функция | Реализация |
|---|---|
| Видео-обои | MP4 / WebM / GIF / MKV / AVI / MOV через LibVLC, аппаратное ускорение (D3D11), бесконечный цикл |
| Веб-обои | Локальные HTML/CSS/JS-страницы и URL через WebView2 (Chromium) |
| Интерактивные обои | Позиция курсора, системный звук (аудио-визуализатор через WASAPI loopback + FFT), время суток |
| Размещение | Безрамочное окно, прикреплённое через WinAPI к WorkerW/Progman за иконками |
| Мониторы | Свои обои и настройки на каждый монитор |
| Пауза | Авто-пауза при полноэкранном приложении (игры), ручная — из трея или окна |
| Свойства обоев | Слайдер / цвет / переключатель / выбор из списка — объявляются в `project.json`, редактируются в GUI, применяются на лету |
| Встроенные регулировки | Скорость, яркость, контраст, насыщенность, громкость, лимит FPS |
| Плейлист | Автосмена по таймеру (по порядку/случайно) и по расписанию |
| Пресеты | Сохранение/загрузка всей конфигурации (обои на мониторах + все настройки + плейлист) |
| Свои файлы | Кнопкой «Добавить», перетаскиванием в окно или копированием в папку библиотеки — без перезапуска |
| Ярлык на рабочем столе | Создаётся автоматически при первом запуске |
| Отдельное окно настройки | Кнопка «🛠 Настройки обоев», двойной клик по миниатюре или ПКМ → «Настроить…»: превью, выбор монитора, все свойства и регулировки, применение на лету |
| Автозапуск | Пункт в настройках (ключ HKCU\...\Run, запуск в трей) |
| Звук обоев | Отдельная глобальная опция + громкость/мьют на каждый обои (по умолчанию выключен) |

Встроенные обои (создаются при первом запуске): **Космос** (параллакс от мыши, время суток),
**Аудио-визуализатор** (реагирует на системный звук), **Часы и время суток**.

## Требования

- Windows 10 (1903+) / Windows 11 x64
- [.NET SDK 8.0](https://dotnet.microsoft.com/download/dotnet/8.0) — для сборки
- WebView2 Runtime — предустановлен в Windows 10/11 (иначе: https://developer.microsoft.com/microsoft-edge/webview2/)
- Аппаратное ускорение видео — любой GPU с драйвером D3D11

## Сборка одной командой

```bat
dotnet build -c Release
```

Готовый исполняемый файл: `Lume\Release\Lume.exe`.
NuGet-пакеты (LibVLC, LibVLCSharp, WebView2 SDK, NAudio) подтянутся автоматически.

### Портативный дистрибутив (одной командой)

```bat
dotnet publish -c Release -o publish
```

Вся папка `publish\` — самодостаточна, можно копировать на другую машину и запускать.

### Установщик и деинсталлятор

```bat
build-installer.bat
```

Скрипт живёт в корне проекта; исходники установщика и готовый файл — в соседней папке
`..\Lume Installer\` (по умолчанию — на рабочем столе рядом с проектом).

Скрипт публикует приложение **самодостаточно** (среда .NET внутри — на целевой машине
ничего ставить не нужно) и собирает **один файл**: `..\Lume Installer\LumeSetup.exe`
(~270 МБ). Его можно скопировать на флешку/в облако и запустить на чистом компьютере —
сборка и папка проекта не требуются. Промежуточные файлы пишутся во временную папку
и удаляются: после сборки проект остаётся чистым.

**LumeSetup** (установка в `%LocalAppData%\Lume` по умолчанию, без прав администратора):
- извлекает встроенные файлы приложения с прогрессом;
- создаёт ярлыки: меню «Пуск» всегда, рабочий стол — по галочке;
- опционально регистрирует автозапуск;
- добавляет Lume в «Установка и удаление программ»;
- кладёт рядом деинсталлятор «Uninstall Lume.exe» (тоже самодостаточный).

**Uninstall Lume** — запускается из «Установка и удаление программ» или прямо из папки:
останавливает работающий Lume, убирает ярлыки, автозапуск и запись в реестре,
опционально удаляет настройки и библиотеку обоев; папку установки подчищает после
своего завершения (включая собственный exe).

Язык установщика и деинсталлятора подстраивается под язык системы (русский/английский).

### Запуск

- `Lume.exe` — обычный запуск (окно библиотеки).
- `Lume.exe --minimized` — запуск свёрнутым в трей (используется автозапуском).

## Установка обоев

### Способ 1 — «Добавить свои обои»
Кнопка в окне приложения → выбрать MP4/WebM/GIF/MKV/AVI/MOV или HTML.
Приложение создаст папку-проект, `project.json` и миниатюру из кадра видео автоматически.

### Способ 2 — перетаскивание
Перетащите видео/HTML-файл прямо в окно приложения.

### Способ 3 — просто скопировать в папку библиотеки
`Документы\VividDesk Wallpapers\`. Можно кинуть:
- готовую папку проекта (с `project.json`);
- папку с видео/HTML без `project.json` — он будет создан автоматически;
- одиночный видеофайл — приложение само превратит его в папку-проект.

Новые файлы подхватываются **без перезапуска** (FileSystemWatcher, папку можно менять в настройках).

### Способ 4 — веб-обои по URL
Кнопка «Веб-обои по URL» → адрес страницы (https://…/http://…).

   popup-окне с корректным Referer (CDN сайта отвергает запросы без реферера).

## Формат папки обоев

Каждый обои — подпапка в библиотеке со структурой:

```
Мой обои/
├── project.json    манифест (ниже)
├── video.mp4       или index.html
└── preview.png     миниатюра (создаётся автоматически, можно заменить своей)
```

### project.json

```json
{
  "title": "Космос",
  "type": "web",              // "video" | "web" | "url"
  "file": "index.html",       // для video/web (для "url" не нужно)
  "url": "https://example.com",  // только для type:"url"
  "preview": "preview.png",
  "description": "Произвольное описание",
  "properties": [
    { "key": "speed", "label": "Скорость звёзд", "type": "slider",
      "min": 0, "max": 2, "step": 0.1, "default": 1 },
    { "key": "tint", "label": "Оттенок", "type": "color", "default": "#3366ff" },
    { "key": "showMoon", "label": "Показывать луну", "type": "checkbox", "default": true },
    { "key": "nebula", "label": "Туманность", "type": "select",
      "default": "purple", "options": ["purple", "teal", "crimson"] }
  ]
}
```

Типы свойств: `slider` (min/max/step/default-число), `color` (строка `#rrggbb`),
`checkbox` (bool), `select` (options — массив строк или `[{"value","label"}]`).
Поля `min/max/step` обязательны только для `slider`.

## JS-API для веб-обоев

В каждую страницу до её загрузки внедряется API `window.wallpaper`:

```js
// значения пользовательских свойств из project.json (типы сохранены: число/строка/bool)
wallpaper.getProperties(props => { console.log(props.speed, props.tint, props.showMoon); });

// реакция на изменение свойств в GUI (применяется на лету)
wallpaper.onPropertiesChanged.addListener(props => { /* ... */ });

// позиция курсора: pt.nx / pt.ny — нормализованные (0..1) координаты монитора,
// pt.x / pt.y — пиксели относительно монитора
wallpaper.onMouseMove.addListener(pt => { /* ... */ });

// аудио-визуализатор: массив из 48 полос спектра системного звука (0..1), ~30 раз/с
wallpaper.onAudio.addListener(bands => { /* ... */ });

// время суток (раз в 30 секунд): { hour, minute, second, iso }
wallpaper.onTime.addListener(t => { /* ... */ });
```

Встроенные регулировки приложение применяет само (без участия страницы):
яркость/контраст/насыщенность — CSS-фильтром к `<html>`, скорость — `playbackRate`
CSS/Web-анимаций и `<video>/<audio>`, лимит FPS — пропуск кадров в `requestAnimationFrame`,
пауза — заморозка анимаций и rAF, мьют — заглушение `<audio>/<video>`.

Примеры использования всех событий — в исходниках встроенных обоев:
`Lume/Core/BuiltinWallpapers.cs`.

## Как это работает (архитектура)

```
Lume/
├── App.xaml(.cs)                 composition root: сервисы, одиночный запуск, трей, восстановление состояния
├── Views/
│   ├── MainWindow.xaml(.cs)       библиотека: миниатюры, мониторы, drag&drop, пресеты
│   ├── WallpaperSettingsWindow.xaml(.cs)  отдельное окно настройки обоев (превью, монитор, свойства)
│   ├── WallpaperSettingsPanel.xaml(.cs)   переиспользуемая панель свойств обоев (окно + библиотека)
│   └── SettingsWindow.xaml(.cs)   настройки приложения + плейлист
├── Wallpaper/
│   └── WallpaperWindow.xaml(.cs)  окно-хост: WorkerW-крепление, рендер видео (LibVLC) или веб (WebView2),
│                                   применение настроек на лету, пауза, рассылка ввода/аудио/времени
├── Core/
│   ├── WinApi.cs                  P/Invoke + поиск слоя WorkerW за иконками (0x052C → Progman)
│   ├── Models.cs                  WallpaperProject / WallpaperSettings / AppConfig / Playlist / Preset
│   ├── ConfigService.cs           config.json в %APPDATA%\VividDesk
│   ├── LibraryService.cs          скан библиотеки, автодетект, импорт файлов/URL, FileSystemWatcher
│   ├── ThumbnailGenerator.cs      кадр видео через libvlc_video_take_snapshot / рисованная миниатюра
│   ├── WallpaperManager.cs        окна на мониторах, паузы, маршрутизация событий
│   ├── ForegroundWatcher.cs       детектор полноэкранного приложения (GetForegroundWindow + монитор)
│   ├── AudioCaptureService.cs     WASAPI loopback + FFT (NAudio), 48 полос
│   ├── InputBroadcaster.cs        глобальная мышь (GetCursorPos) + время суток
│   ├── PlaylistManager.cs         автосмена: таймер + расписание
│   ├── PresetService.cs           экспорт/импорт пресетов (.vdpreset)
│   ├── AutoStartHelper.cs         автозапуск (HKCU Run)
│   ├── TrayController.cs          иконка в трее (рисуется кодом)
│   ├── WebApiScripts.cs           JS-инъекция: window.wallpaper API + фильтры/FPS/пауза
│   └── BuiltinWallpapers.cs       три встроенных интерактивных обоев
├── app.manifest                   PerMonitorV2 DPI, asInvoker
└── Lume.csproj
```

Поток данных: `LibraryService` находит проекты → `MainWindow` показывает миниатюры →
`WallpaperManager.Apply` создаёт `WallpaperWindow` на выбранном мониторе → окно цепляется
к WorkerW и рендерит контент → `InputBroadcaster`/`AudioCaptureService` поставляют в WebView2
данные событий → настройки применяются методами `ApplySettings` без перезапуска.

### Технические заметки

- **Крепление к столу**: `SendMessage(Progman, 0x052C)` → поиск `SHELLDLL_DefView` →
  `SetParent` на соседний `WorkerW`. Иконки остаются поверх обоев.
- **Лимит FPS видео**: у LibVLC нет API ограничения частоты вывода, поэтому для лимита < 24
  используется кадровое окно (короткий play + пауза каждые 1000/limit мс); ≥ 24 или 0 — без изменений.
- **Пауза «стоп-кадр»** у видео — `libvlc_media_player_set_pause`, у веб — заморозка анимаций/rAF;
  режим «полная остановка» — `Stop()`/`Navigate("about:blank")` (максимальная экономия).
- **Миниатюра видео** — честный кадр: скрытое окно рендера + `libvlc_video_take_snapshot`.

## Конфигурация

- `%APPDATA%\VividDesk\config.json` — все настройки, обои на мониторах, плейлист.
- `%APPDATA%\VividDesk\error.log` — журнал ошибок (если пуст/отсутствует — всё хорошо).
- `Документы\VividDesk Wallpapers\` — библиотека обоев (путь меняется в настройках).

## Известные ограничения

- **Скрытое окно «VLC video main» при видео-обоях.** libVLC 3 создаёт служебное
  event-окно vout-модуля (настоящий top-level, `parent=0`), пока играет видео.
  Проверено экспериментально: SetParent (задержки 0.4с и 2с), перевод стиля в
  WS_CHILD и WM_CLOSE на живом рендере роняют процесс нативно — в этом окне
  живёт message-pump цикла вывода. Окно существует в единственном экземпляре,
  скрыто и удаляется при уходе с видео (WM_CLOSE после остановки плеера).
  Убрать его на живом рендере можно только сменив видеотракт (vmem-колбэки /
  Media Foundation / VLC 4).
