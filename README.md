# Lume — живые обои для Windows 10/11

Бесплатное приложение для анимированных обоев на рабочем столе: видео, веб-страницы и картинки
за иконками рабочего стола. Библиотека обоев, настройки на каждый монитор, живая заставка
по бездействию, кадр текущих обоев на экране блокировки.

## Установка

1. Скачайте `LumeSetup.exe` из раздела **Releases** (≥ 235 МБ).
2. Запустите — установка идёт в `%LOCALAPPDATA%\Lume`, права администратора не нужны.
3. Поставьте галочку «Запустить», если хотите открыть приложение сразу.

Требования: Windows 10 1903+ / Windows 11, x64. .NET устанавливать не нужно — сборка self-contained.
WebView2 Runtime нужен только для веб-обоев (на Windows 11 уже есть, на Windows 10 при отсутствии
приложение работает, но веб-обои не отрисуются).

**Контрольная сумма релиза**

```
LumeSetup.exe  246 125 851 байт
SHA256: D7C6A9E65DD1EF0AA72167E7DE6E9FB71972CF22D2AA244F5E142CEAB92ABC04
```

Проверить после скачивания:

```powershell
Get-FileHash .\LumeSetup.exe -Algorithm SHA256
```

## Что умеет

| Возможность | Как реализовано |
|---|---|
| Видео-обои | MP4 / WebM / MKV / AVI / MOV / M4V / WMV / FLV / TS / M2TS / OGV через LibVLC, аппаратное ускорение D3D11, бесконечный цикл |
| GIF как обои | Анимированный GIF играется тем же движком |
| Картинки | JPG / PNG / WEBP / BMP — статичные обои с масштабированием |
| Веб-обои | Локальные HTML/CSS/JS и URL через WebView2 |
| Интерактив | Позиция курсора, системный звук (WASAPI loopback + FFT), время суток доступны странице |
| Слой обоев | Безрамочное окно, прикреплённое через WinAPI к WorkerW за иконками |
| Мониторы | Свои обои и настройки на каждый монитор |
| Пауза | Авто-пауза при полноэкранном приложении и вручную из трея |
| Настройки обоев | Слайдеры / цвета / переключатели / списки, объявленные в `project.json` |
| Регулировки | Скорость, яркость, контраст, насыщенность, громкость, лимит FPS |
| Плейлист | Автосмена по таймеру и по расписанию |
| Пресеты | Сохранение и загрузка конфигурации целиком |
| Импорт | Перетаскивание файлов и ZIP-архивов, автоопределение формата |
| Живая заставка | По бездействию показывает анимированные обои с часами; любой ввод блокирует сеанс |
| Экран блокировки | Кадр текущих обоев как картинка локскрина |
| Масштаб обоев | 50–150 % для видео, веб и картинок |
| Избранное | Библиотека в `wallpapers` рядом с приложением, ярлык на рабочем столе, автозапуск |

Встроенные обои создаются при первом запуске: **Космос** (параллакс от мыши), **Аудио-визуализатор**
(реагирует на системный звук), **Часы и время суток**.

## Какие форматы обоев поддерживаются

Lume — не Wallpaper Engine, форматы у них разные:

| Источник | Статус |
|---|---|
| Видео (mp4, webm, mkv, avi, mov, wmv, flv…) | **работает** |
| GIF, JPG, PNG, WEBP, BMP | **работает** |
| Веб-обои (папка с `index.html` + `project.json`) | **работает** |
| ZIP с обоями (в т.ч. с вложенной папкой) | **импортируется автоматически** |
| Сцены Wallpaper Engine (`scene.pkg`, `type: scene`) | **не рендерятся**: нужен движок WE. Lume вытащит из пакета видео, если оно там есть, иначе поставит `preview.gif` / `preview.jpg` |
| Обои типа `application` (запуск стороннего exe) | **не поддерживаются** — по соображениям безопасности |

## Удаление

`Параметры → Приложения → Lume → Удалить` либо `Uninstall Lume.exe` в папке установки.
Обои при обычном удалении переносятся в `Документы\Lume Wallpapers`; при удалении с галочкой
«также удалить настройки и обои» стираются и они.
